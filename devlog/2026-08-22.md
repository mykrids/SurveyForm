## RESEND 점검 — krids.org DNS 실측 (2026-08-22 23시)

### 점검 방법
- `https://dns.google/resolve` API로 `krids.org / send.krids.org / resend._domainkey / _dmarc / *.krids.org` TXT/MX/CNAME 전수 조회 + `POST https://api.resend.com/emails` 테스트 발송 (`re_dBuCa9MS_...` send-only 키)

### 결과: 발송 자체는 정상이나 배달률 저하 요인 3건 — 코딩 종료 후 일괄 수정으로 보류 (사용자 승인)

| 구분 | 현재 | 판정 |
|------|------|------|
| `krids.org TXT SPF` | `v=spf1 include:zohomail.com ~all` | ❌ `include:amazonses.com` 누락 — FROM이 `noreply@krids.org`(`.env:6`)라 `krids.org` SPF가 검사 대상, `send.krids.org` 의 `amazonses.com` 은 미검사 → SPF fail |
| `send.krids.org TXT` | `v=spf1 include:amazonses.com ~all` | ⚠️ 위치 오류 아님, return-path용으론 유지 |
| `resend._domainkey.krids.org` | `p=MIGfMA0...` (218자, `v=DKIM1; k=rsa;` prefix 없음) | ❌ Cafe24 입력 시 prefix 잘림 — `v=DKIM1; k=rsa; p=...` 로 교체 필요 (Resend Dashboard > Domains > krids.org DKIM 값 기준) |
| `*.krids.org CNAME → krids.org` | TTL 1800 존재 (Cafe24) | ❌ 최우선 삭제 — `brevo._domainkey` 등 모든 미존재 서브도메인이 `krids.org` TXT를 반환해 Brevo/향후 SES DKIM 검증 차단 실측 (`thisshouldnotexist12345.krids.org` 도 동일) |
| `_dmarc` | `v=DMARC1; p=none; rua=mailto:rua@dmarc.brevo.com` | ⚠️ 당장 차단 없음이나 Brevo DKIM 깨져 리포트 신뢰 낮음 |
| 테스트 발송 | `POST /emails` → `id 223b07a4-54f6-4fc3-82fe-831de67225f6` | ✅ 키 유효, 당장 개발/테스트 지장 없음 |

- 코드(`src/lib/email.ts:15,36`)와 `.env:6` 은 이미 `noreply@krids.org` 로 반영됨. DNS만 남음.
