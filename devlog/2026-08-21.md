## 인증 가이드 (다음 세션에서 순서대로 진행)
### 1) Google Cloud + Forms API
1. console.cloud.google.com → 새 프로젝트 → API 및 서비스 > 라이브러리 → Google Forms API 사용 설정
2. IAM > 서비스 계정 → 만들기 → 키 탭 → JSON 발급 → 안전한 곳 보관
3. 테스트용 Google Form 생성 → 우측 상단 공유 → 서비스계정 이메일(xxxx@...iam.gserviceaccount.com)에 뷰어 권한 부여 (누락 시 403)
4. .env에 GOOGLE_SERVICE_ACCOUNT_JSON_PATH 또는 GOOGLE_SERVICE_ACCOUNT_JSON 설정

### 2) GAS + Sheets
1. 응답 저장용 Google Sheet 생성 → 확장 프로그램 > Apps Script → gas/Code.gs 붙여넣기
2. Script Properties에 SHARED_SECRET 등록 (Next.js GAS_SHARED_SECRET과 동일 값)
3. 배포 > 새 배포 > 웹 앱 → 액세스: 모든 사용자 → URL 복사 → .env GAS_WEBAPP_URL에 등록
4. 관리자 패널에서도 설문별 GAS URL 개별 설정 가능

### 3) Supabase
1. supabase.com → 프로젝트 생성 → Settings > API → URL/anon key/service_role key 복사 → .env 등록
2. SQL Editor에서 supabase/schema.sql 실행 (surveys, survey_responses_log)
3. .vscode/mcp.json의 project_ref=bpvvxsrtfigphxzoztjm가 이미 있으면 해당 프로젝트 사용

### 4) Resend
1. resend.com → API Key 발급 → .env RESEND_API_KEY 등록, RESEND_FROM 설정
2. Domains에서 발신 도메인 DNS 인증 (스팸함 방지 권장)

### 5) Vercel Cron
1. vercel.json의 crons가 자동 인식 — Vercel 대시보드 > Settings > Environment Variables에 CRON_SECRET 등록
2. Cron 호출 시 Authorization: Bearer <CRON_SECRET> 또는 x-cron-secret 헤더로 보호됨
